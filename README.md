# 🌊 Ghostnet Net Fishing

## 📌 Projektbeschreibung
Dieses Repository enthält den Prototyp der Webanwendung „ghostnet-project“, entwickelt im Rahmen des Moduls „Programmierung von industriellen Informationssystemen mit Java EE“ (IPWA02-01).
Die Webanwendung der Non-Profit-Organisation *Shea Sepherd* dient dazu, das Melden und Bergen von Geisternetzen zu vereinfachen. Nutzer:innen können anonym Geisternetze melden. Registrierte Benutzer:innen haben zusätzlich die Möglichkeit, sich für Bergungen einzutragen, Statusänderungen vorzunehmen und die Kontaktdaten bergender Personen einzusehen.

## 🛠️ Technologien
- Jakarta EE (JSF, CDI)
- PrimeFaces
- JPA (Hibernate) für den Datenbankzugriff
- Maven (Build-Tool)
- MySQL-Datenbank mit Persistence Unit `ghostnet-ProjectPersistenceUnit`

## ⚙️ Einrichtung 
- Projekt in einer IDE (z. B. Eclipse) öffnen
- Eine MySQL-Datenbank erstellen oder starten
- Die Datei `persistence.xml` anpassen (Datenbank-URL, Benutzername, Passwort)
- Projekt auf einem Application Server (z. B. Apache TomEE) starten
- Anwendung im Browser aufrufen
